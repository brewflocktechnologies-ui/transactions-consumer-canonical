# transactions-consumer-canonical

Spring Boot service for storing and managing canonical SEND_TRANSACTIONS and related child tables (SEND_TRAN_DTL, SEND_RECIP_DTL, SEND_TRAN_ADDR_DTL). Provides REST endpoints to upsert, query (by id + paginated list) and delete transactions. Includes DB init SQL and a Postman collection with examples.

## Tech
- Java 25, Spring Boot 3.5.14
- Spring Web, Spring JDBC, Spring Validation, Spring Actuator
- Kafka client (spring-kafka)
- Oracle (ojdbc11) runtime
- Lombok (compile-time)
- Maven (wrapper included)

The script expects an Oracle user `SEND_TXN_OWNER` — create the user and grant CREATE TABLE/SESSION/UNLIMITED TABLESPACE before running.

## API
Base path: `/api/v1/send-transactions`
- PUT /{tranId} — Upsert parent and optional children. Behavior:
  - Omit `tranDtl` / `recipDtl` → existing child rows untouched
  - Include `tranDtl` / `recipDtl` → merged (insert or update)
  - Include `addrDtl` as `[]` → deletes all addresses; omit `addrDtl` to leave addresses unchanged
- GET /{tranId} — Retrieve full nested graph (parent + tranDtl + recipDtl + addrDtl[])
- GET /?page={page}&size={size} — Paginated list of parents (default page=0,size=20, max size=100)
- DELETE /{tranId} — Delete children then parent (returns 204)

See `postman/Send_Transactions_API.postman_collection.json` for ready examples and collection variables (`baseUrl`, `tranId`).

## Examples
Minimal upsert (curl):

curl -X PUT "http://localhost:8080/api/v1/send-transactions/TXN-001" \
  -H "Content-Type: application/json" \
  -d '{ "tranType":"SEND", "tranCrteDt":"2024-11-15T09:30:00", "tranAmt":1500.00, "tranCurr":"USD" }'

Get by id:

curl -X GET "http://localhost:8080/api/v1/send-transactions/TXN-001"

Delete:

curl -X DELETE "http://localhost:8080/api/v1/send-transactions/TXN-001"
